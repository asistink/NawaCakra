# PRD — Website Pitching KKN Nawa Cakra

## 1. Ringkasan Proyek

| Item | Keterangan |
|---|---|
| **Nama proyek** | Website Pitching KKN Nawa Cakra |
| **Tim** | Nawa Cakra — KKN PPM UGM Periode II 2027 |
| **Lokasi** | Desa Kukuh (Kec. Marga) & Desa Kerambitan (Kec. Kerambitan), Tabanan, Bali |
| **Tujuan utama** | Menjadi media pitching kepada dosen pembimbing, LPPM UGM, dan calon sponsor |
| **Audiens** | Pengelola KKN (dosen/LPPM), sponsor, dan publik umum |
| **Bahasa** | Indonesia |
| **Timeline** | MVP selesai dalam ±1 minggu (deadline pitching) |
| **Budget** | Hosting gratis dulu (Vercel), domain `.id` menyusul jika diperlukan |

## 2. Masalah & Tujuan

**Masalah:** Tim KKN Nawa Cakra belum memiliki media digital yang memamerkan program kerja, potensi desa, dan kepercayaan diri tim saat pitching — khususnya untuk meyakinkan sponsor.

**Tujuan (urut prioritas):**
1. Meningkatkan kesan profesionalisme tim saat pitching ke LPPM/dosen pembimbing.
2. Menarik sponsor melalui section paket kerjasama yang jelas + CTA kontak.
3. Menjadi profil publik yang bisa dibagikan via QR code / link WhatsApp.

**Metrik keberhasilan:**
- MVP live sebelum H-day pitching.
- Link website dibagikan minimal pada 1 sesi pitching resmi.
- Minimal 1 pihak sponsor/relasi menghubungi tim via CTA.

## 6. Teknologi (Tech Stack disetujui)

- **Next.js (App Router)** + **Tailwind CSS** — performa bagus, ekosistem komponen terlengkap.
- **GSAP + ScrollTrigger + Lenis** — smooth scroll & animasi ala pionir.ugm.ac.id/2026 (parallax, reveal, counter).
- **shadcn/ui + Aceternity UI** — komponen siap pakai bergaya modern.
- **Deploy:** Vercel (gratis, zero maintenance). Domain `.id` opsional nanti.
- **Google Maps:** embed iframe Desa Kukuh (tanpa API key).
- **Media kit:** PDF 1 halaman yang bisa diunduh dari section sponsor.

## 7. Fitur Dinamis (MVP vs Pasca-MVP)

**MVP (1 minggu):**
- Animasi on-scroll (reveal, parallax, counter angka)
- Sticky nav + smooth scroll
- Akordeon/expandable untuk proker per klaster
- Google Maps embed
- QR code (dibuat dari URL website)
- SEO meta + OG image (agar bagus saat share di WhatsApp)
- Media kit PDF downloadable

**Pasca-MVP (opsional):**
- Form kontak/intent sponsor (via Formspree atau Google Form)
- Galeri dokumentasi dinamis
- Versi bahasa Inggris
- Halaman terpisah per klaster
- CMS (kalau user ingin mengupdate konten tanpa edit kode)

## 8. Risiko & Mitigasi

| Risiko | Mitigasi |
|---|---|
| Waktu 1 minggu pendek | Prioritas P0 dulu; P1 bisa setelah pitching |
| Belum ada logo tim & foto asli | Placeholder sederhana + foto stock; tidak menghalangi pitching |
| Isi proker sangat panjang | Ringkas per proker menjadi 1–2 kalimat + akordeon untuk detail |
| Konten tim belum lengkap | Section tim dibuat dengan struktur siap; data tinggal diisi |

## 9. Hal yang Perlu Dikonfirmasi User

1. Kontak CTA (WA/IG/email) — akan diisi sendiri.
2. Nama lengkap & fakultas & foto anggota (Raka, Ardi, Angel, Ilma, Gea).
3. Finalisasi nominal & benefit paket sponsor.
4. Nomor kelompok (muncul nanti) — punya slot placeholder di hero.
